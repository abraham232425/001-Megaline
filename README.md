# 001-Megaline

## ANÁLISIS PARA LA EMPRESA DE TELECOMUNICACIONES MEGALINE.

## 📊 Realizar análisis de datos para la empresa Megaline para realizar un modelo predictivo sobre cada plan tarifario que ofrece al publico.

## Problema de Negocio.
* El departamento comercial de Megaline desconoce cuál de sus dos tarifas de prepago (Surf o Ultimate) genera mayores ingresos por cliente. 
Sin esta información, la empresa corre el riesgo de destinar presupuesto publicitario e inversión de marketing de manera ineficiente en planes menos rentables o de menor crecimiento.

## ¿Qué problema se intenta resolver? 
* Se busca determinar de manera cuantitativa y estadísticamente validada qué tarifa de prepago genera más ingresos promedio para Megaline.
  Esto permitirá optimizar la estrategia comercial y la asignación del presupuesto publicitario.
## ¿Qué preguntas de negocio o hipótesis busca responder este análisis?
Preguntas de negocio:
* ¿Cuál es el comportamiento de consumo (minutos de llamada, mensajes de texto y volumen de datos de internet) de los usuarios de cada plan durante el año 2018?
* ¿Qué proporción de usuarios en cada tarifa excede los límites mensuales de su paquete básico y genera ingresos adicionales por tarifas excedentes?
* ¿Cuál de los dos planes (Surf o Ultimate) aporta un ingreso promedio mayor por usuario al año/mes?
  
## ¿Por qué surge este proyecto?
* El proyecto surge de la necesidad del departamento comercial de basar sus decisiones estratégicas en datos reales.
  En lugar de distribuir el presupuesto publicitario a ciegas o por intuición, se requiere realizar un análisis preliminar sobre una muestra representativa de 500 clientes del año 2018
  para justificar el enfoque de las campañas de marketing hacia el producto más lucrativo.

## ¿A qué industria, área o problema pertenece?
* Industria: Telecomunicaciones (Servicios Móviles / Prepago).
* Área: Analítica de Negocio (Business Analytics), Inteligencia Comercial y Estrategia de Marketing.
* Problema: Optimización del Retorno de Inversión (ROI) publicitario, monetización de tarifas y análisis de patrones de consumo de clientes (Customer Behavior Analytics).
## ¿A quién van dirigidos los resultados (stakeholders, público en general, equipo técnico)?
* Stakeholders principales: Departamento Comercial, Directores/Gerentes de Marketing y Estrategia de Producto (para decisiones de presupuesto y ofertas).
* Equipo técnico / Analistas: Para revisión de la metodología, limpieza de datos y validación de las pruebas estadísticas aplicadas.
  
## 🎯 Objetivos del Proyecto

## 🎯 Objetivo Principal: 

* Explicar claramente la meta global (ej. Identificar los factores clave de fuga de clientes en un servicio de suscripción).

## 🎯 Objetivos Específicos:

* Limpiar y preparar la base de datos para garantizar la calidad de la información.
  
* Realizar un Análisis Exploratorio de Datos (EDA) para detectar patrones y correlaciones.

* Diseñar visualizaciones e indicadores clave (KPIs) claros e intuitivos.

* Formular recomendaciones estratégicas basadas en los hallazgos.

## 🔬 Metodología del Análisis

Describe brevemente la lógica de trabajo aplicada:

* Limpieza y Preparación: Tratamiento de valores nulos, eliminación de duplicados y conversión de tipos de datos.

* Análisis Exploratorio (EDA): Identificación de distribuciones, outliers y correlaciones entre variables.

* Modelado / Transformación (si aplica): Segmentación, cálculo de métricas o modelos predictivos.

* Visualización: Creación de dashboards o visualizaciones ejecutivas para presentar la información.
